# Roadmap

The roadmap is directional. Proposals and pull requests are welcome.

## Near term

- Expand automated tests for imports, authentication, permissions, and structured metadata
- Add a documented PostgreSQL production profile
- Improve accessible keyboard behavior and reduced-motion coverage
- Add background job persistence for large prompt imports
- Provide starter deployment guides for common hosting and object-storage providers

## Later

- Pluggable search backends and semantic discovery
- Versioned prompt revisions and editorial review queues
- Import/export adapters for additional prompt formats
- Contributor attribution and moderation workflows
- Internationalized public pages and metadata
