# Changelog

All notable changes to PromptVault OSS are documented here.

## [1.0.0] - 2026-07-16

### Added

- Initial sanitized open-source release
- Public prompt library, collections, topic hubs, trending pages, and prompt details
- Account, saved-prompt, profile, API-key, and administrator workflows
- Blog editor with JSON imports and SEO/AEO/GEO fields
- ZIP prompt imports with image processing and validation
- Safe SQLite demonstration seed and original SVG demo artwork
- Configurable branding, site URLs, storage, email, and authentication settings
- CI, security policy, contributor guidance, issue templates, and Apache-2.0 license

### Security

- Excluded production databases, accounts, uploads, secrets, logs, deployment scripts, verification files, and private repository history
- Removed fallback administrator credentials and machine-specific filesystem paths
