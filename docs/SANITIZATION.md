# Sanitization record

This repository was created from a clean working copy rather than publishing the production repository or rewriting its history.

The public edition excludes:

- SQLite databases, journals, and database exports
- User accounts, password hashes, emails, messages, subscriptions, and analytics records
- Production prompt and article records
- Uploaded or generated production images
- Environment files, API tokens, session secrets, storage credentials, and email credentials
- Web-server configuration, machine-specific paths, operational scripts, logs, and verification files
- Private Git history and internal audit notes

The included seed uses synthetic demonstration records and requires the operator to supply a local administrator email and password. The images in `public/demo` are original SVG placeholders created for this public edition.
